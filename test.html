Automated IoT Cleaning System

الجيل القادم من أنظمة التنظيف الذكية باستخدام الموائع المغناطيسية و IoT

مكونات النظام (Hardware)

Pump & Nozzle

مضخة عالية الضغط متصلة برشاشات دقيقة لضمان توزيع السائل المغناطيسي بشكل متساوي على السطح.

Electromagnet

قلب الابتكار: مغناطيس كهربائي يتم التحكم فيه برمجياً لتوجيه وجمع السائل بعد عملية التنظيف.

Vacuum System

شفاط مخصص لسحب البقايا النهائية وضمان جفاف السطح بنسبة 100%.

Robot / Rail

نظام حركة ميكانيكي (Moving Rail) يضمن وصول النظام لجميع زوايا اللوح المستهدف.

الذكاء البرمجي و IoT

Microcontroller: ESP32

العقل المدبر للنظام، يدعم الاتصال بشبكة Wi-Fi للتحكم عن بُعد ومعالجة الأوامر اللحظية.

// VS Code Snippet
void startCleaningCycle() {
  digitalWrite(PUMP_PIN, HIGH);
  Serial.println("System Running...");
}

تطبيق الموبايل (IoT Features)

  • 📱 تشغيل وإيقاف النظام بضغطة واحدة.
  • 📊 مراقبة حالة السائل ومستوى البطارية.
  • 📅 جدولة عمليات التنظيف (Daily/Weekly).

دورة عمل النظام (Workflow)

1

بدء التشغيل

يستقبل الـ ESP32 أمراً عبر الإنترنت ويبدأ في معايرة الحساسات.

2

ضخ السائل المغناطيسي

يتم رش السائل الذي يلتقط ذرات الغبار والأتربة بقوة الالتصاق الجزيئي.

3

التجميع المغناطيسي

يعمل المغناطيس الكهربائي على سحب السائل (المحمل بالأتربة) إلى نقطة التجميع.

4

الشفط والإنهاء

يعمل الشفاط لإزالة أي بقايا، ثم يعود النظام لوضع الاستعداد.
